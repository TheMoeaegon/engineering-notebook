# Engineering Notebook

Personal engineering notebook — short notes on whatever I'm learning about technology, computers, and systems.

These are working notes, not polished articles. The goal is to write down how something works while I'm learning it, so I can come back later and remember *why* it works that way.

## Notes

| Note | What it covers |
| --- | --- |
| [Build Asteroids](./build-asteroids.md) | Building an Asteroids clone with Python + Pygame: the game loop, FPS and delta time, sprite groups, movement, drawing, shooting, and collisions. |
| [OOP Notes](./oop-notes.md) | Object-oriented programming from first principles: classes, objects, methods, encapsulation, abstraction, inheritance, and polymorphism. |
| [Caching Proxy](./Caching%20Proxy.md) | Building a small HTTP caching proxy with Bun + TypeScript — HTTP caching, revalidation, and cache headers. |
| [How to Build an MCP Server](./how-to-build-MCP-Server.md) | Building a Model Context Protocol server with FastMCP — tools, SSE transport, and testing. |

## Structure

- Each note is a single Markdown file at the repo root.
- Screenshots, diagrams, and videos live in [`media/`](./media).
- Notes may mix course material with my own explanations and examples; sources are cited at the top where relevant.

## Why keep a notebook?

Writing an explanation forces me to find the gaps in my understanding. If I can't explain it simply, I probably don't understand it yet — and these notes are where that explanation gets written down and corrected over time.
